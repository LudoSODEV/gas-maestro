Importer should hold an array of FileSniffer instances. Currently, there's only AssoConnectFileSniffer. When a file is staged, the importer iterates through file sniffers and collect the available actions to present them to the user. The action should be returned as a string to describe the action, and a value or values used to trigger the action on given document. They are used to create an action button. The AssoConnectFileSniffer returns actions performed by AssoConnectImporter.
